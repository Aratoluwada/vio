## Pending Before M1 Can Close

1. **Groq model IDs and calibration protocol:** identify suitable free-tier models/families for each role (`extractor`, `safety`, `consistency`, `red_team`, `summary_check`), pin model IDs/versions and prompt versions, and define calibration data split and minimum evaluation criteria. Check current Groq free-tier limits; if a role lacks a suitable option or quota is exhausted, stop and report it, with no paid fallback.
2. **Timetable evidence and variant learning:** timetable does not change personal trust and is not required to file. It verifies declared department/level and course eligibility. Decide operational evidence criteria and how many independent submissions create a candidate variant. Candidate variants require course/department and source validation; do not infer college ownership from frequency alone.
3. **Recency implementation dependency:** the numeric schedule is set above, but enforcement requires sourced teaching-period/exam dates and verified course registration history. If the date data is unavailable, the endpoint should return eligibility/pursuit priority as unknown rather than inventing calendar boundaries.
4. **Small-class privacy implementation dependency:** the 20-student minimum is approved. Suppression must use group enrollment, not finding count. Enrollment data is not currently available in the schema, so public breakdowns must be withheld or broadened until a safe denominator exists.
5. **Panel/timing dependency:** exact Groq model IDs/families and calibration remain open; the selected `0.80` threshold is provisional until calibrated on the golden set. Free-tier quota exhaustion means hold/retry later, never downgrade to a paid model.
6. **False-outcome policy conflict:** school responses may be retained as external evidence, but an automatic trust penalty based on a human school decision may conflict with the core prohibition on humans in VIO's decision loop. Do not enable the penalty until this boundary is explicitly resolved; no human moderator queue is to be introduced.
